# Инструкция по начальной настройке запуска автотестирования

## Информация

1. Проект находится в каталоге "D:\NetologyDiplomaProjectAlievAZ".
2. Информационная база (ИБ) в папке "IB".
3. Все вспомогательные файлы и инструкции в каталоге "D:\NetologyDiplomaProjectAlievAZ\NetologyDiplomaProjectAlievAZ", далее 1.
4. Должны быть установлены Visual Studio Code, OneScripts. Установите расширение для VSCode "Cucumber Gherkin Full Support".
5. Скачайте фреймворк Vanessa Automation.
6. Платформа 1С должна быть с комьюнити-лицензией.

## Подготовка к запуску

1. В конфигураторе загрузите информационную базу Demo_DP_Alievaz.dt.
2. Там где утановлена платформа 1С в папке "conf" открываем файл "conf.cfg" под администратором, добавляем строку "DisableUnsafeActionProtection=DiplomTest" (так называется у меня ИБ для теста) и сохраняем.
3. Запустите 1С:Предприятие с дополнительным параметром /TESTMANAGER под администратором.
4. Откройте в 1С файл внешней обработки vanessa-automation.epf, находящийся в каталоге Vanessa Automation.
5. Далее откройте фича-файл "ОбщийСценарий" из каталога 1. Остальные фича-файлы экспортные.
6. В закладке "Библиотеки" добавляем каталог 1 и сохраняем настройки.
7. Автотестирование готово к запуску.
